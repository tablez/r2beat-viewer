2026-10-21 更新：
- 摸鱼主题障碍恢复原色，隐藏右侧指法/按键提示。
- 播放、手痒和听歌模式提供 0.5–1.5 倍速滑条，步进 0.1，音乐和谱面时钟同步变速。
- 顶部改键开关：默认 ↑E / ↓J / ←F / →I，支持自定义；勾选后原方向键和小键盘仍然生效，设置保存在当前浏览器。
- 新增 [专项练习](https://r2.zako.cc/practice.html)：基础适应、浮云、盾、子弹、梯子、枪，可多选混合；按所选类型每轮重新随机生成，独立计分，绿色上箭头/红色下箭头比较上一轮。
- 基础适应严格等间隔，100% 上下左右随机单方向，不生成斜向组合键；练习页使用节拍提示音，不依赖歌曲音乐包。

专项练习规则修订：所有类型均为上下左右单键。浮云为 LRL/RLR 三连且组间加上、下或上下；盾为上上/下下并穿插左右；子弹以 LLRR/RRLL 为核心并加入不规则左右；梯子是连续密集长串左右交替；枪为单方向 4–8 次。每轮重新按组随机组织，保留类型结构；混合练习优先盾和浮云，其次子弹。
